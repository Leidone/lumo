# Getting help

1. **Check [Troubleshooting](docs/TROUBLESHOOTING.md).** It covers the first launch, permissions that seem to do nothing, the Dynamic Island, shortcuts and CPU use.
2. **Look through existing issues.** Someone may have hit the same thing.
3. **Open an issue** with the bug report template. Include your macOS version, Mac model, the Lumo version (Settings → About) and the steps that lead to the problem. Screenshots help.

Ideas are welcome too — use the feature request template and describe the problem you want solved, not just the solution.

Security problems: please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
