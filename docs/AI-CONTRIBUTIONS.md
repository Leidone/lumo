# AI-assisted contributions

Lumo itself was built with the help of an AI coding assistant (Claude Code), reviewed and directed by the maintainer. AI-assisted contributions are welcome on the same terms as any other.

What we ask:

- **You are the author.** Read, understand and test everything you submit. "The AI wrote it" is not an explanation for a bug.
- **Run `swift test`** and try the change in a real build on a Mac. For features that need permissions, test them with those permissions granted.
- **Keep the rules in [CONTRIBUTING](../CONTRIBUTING.md):** off by default, minimal permissions, no idle cost, no hidden network calls, both languages.
- **No copied code.** Don't paste code generated from — or copied out of — projects under licenses incompatible with MIT (for example GPL projects), and don't reproduce other apps' branding or design.
- **Say so in the pull request** if a tool wrote a significant part of it. It's not a mark against the PR; it helps reviewers know where to look harder.
